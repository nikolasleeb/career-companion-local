# Career Companion Local 1.0.12

This release brings the current reviewed hosted functionality to the sanitized localhost edition. Installations start empty; hosted accounts, data, credentials and deployment configuration are not included.

- Profile: structured application names and international address/postal fields, separate resume name, class identities and syllabus review, and linked Supporting Details alongside entries.
- Application Assistant: top-to-bottom supported filling, searchable School/Employer choices and repeated history rows, explicit saved Personal Details reuse, and matching saved work-authorization/sponsorship answers. Private values remain excluded from general AI and professional documents.
- Resume workflow: Standard uses two AI requests normally and at most four with a material correction, saves recoverable previews and pauses under its five-minute budget. Explicit finalization/manual review and Cover Letter navigation are separate controls. Existing optimizer limitations are not described as fixed by packaging this release.
- Documents: clearer certifications, controlled public profile links, uploaded-resume selection, and preserved historical versions.
- Writing guide: brings the hosted practical handbook and source-linked examples into the public edition.
- Documentation: a source-verified Profile/AI data-use chart and permission matrix; updated Chrome/Safari installation instructions.

## Downloads

Choose the `linux-amd64` image archive for Intel/AMD or `linux-arm64` for ARM64. The release includes Compose, quickstart, a clean source ZIP, browser extension ZIPs and checksums. The signed/notarized Safari installer is a separate macOS download; installing it does not pair the browser or start filling. Browser core version remains 1.0.9.

Both Docker architectures must pass offline backend tests and clean-account smoke checks. Downloadable image archives are loaded and checked before publication. The Safari distribution must pass signing, notarization and stapling checks. No paid user-account request is part of release validation.

The separate NAS-ready hosted image is prepared privately for linux/amd64. It is not a public release asset, contains no live data or secrets, and is not transferred or installed on the NAS.

Save work and back up existing local data and vault-key volumes before installing an update. This release process does not update installed localhost, replace the running hosted service or migrate accounts.
