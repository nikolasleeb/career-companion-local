# Career Companion Local 1.0.0

First clean public localhost edition with fresh source history and no operator deployment files or machine-specific documentation.

- Local account registration, profile and supporting details, job-document parsing, resume and cover-letter builders, private disclosures, and Work Styles.
- Loopback-only published ports, fixed local hosts, and localhost browser connections.
- Account-owned OpenAI keys; no shared key included.
- Settings shows installed image metadata and checks complete stable GitHub releases with daily caching and manual refresh.
- Separate x64 and ARM64 downloadable image archives, checksums, and Compose instructions.

Source builds display Custom build. Updates are installed manually after saving work and backing up both data volumes.
