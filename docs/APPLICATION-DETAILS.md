# Application details

Open an application to see three tabs. **Progress & history** opens Activity directly.

- **Overview:** change status and relevant dates, keep notes, or expand Edit job details. The status-change date defaults to today and stays editable.
- **Documents:** upload a resume, select the exact version submitted, and keep cover letters and supporting files together. Each file appears once. More contains Rename, alternate download formats, or Remove where available.
- **Activity:** read the status timeline and interview rounds. Add or Edit reveals the fields for that entry. Historical updates do not change the current status; use Overview for that.

## Use a resume already uploaded as Other

In Documents → Resumes, choose **Choose an existing uploaded file**, select the file, and choose **Use this file as a resume**. This reuses its original bytes without another upload. Then choose **Use as submitted** and **Save changes** if this is the exact version sent to the employer.

Promotion does not change the application status or submitted version automatically. An uploaded resume still needs its text reviewed before AI cover-letter drafting.

## Saving

Application edits stay pending across tabs. **Save changes** saves them and keeps the popup open; the button disappears when there are no pending application edits. Close warns before discarding unsaved edits.

Uploads, renames, and file removal are separate explicit actions and save immediately. Their short completion messages appear with the affected file. Closing without saving application edits does not undo file actions already completed.

Status, submitted-version, and note edits survive file uploads and promotion. If another window changes the application, a stale save is rejected instead of overwriting it. Reload saved changes only when ready to discard the local pending application edits.

Original downloads, account ownership checks, reviewed source history, deletion guards, and exact-version extension approvals remain in place. Routine filling uses no AI and never submits the employer form automatically.
