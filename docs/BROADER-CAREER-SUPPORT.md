# Broader career support

Action Plans preserves the dedicated planning chats and roadmap versions. The circular Career Coach opens a read-only account-scoped assistant beside any signed-in page. It retrieves reviewed professional evidence, aspirations, approved work preferences and saved outputs with SQLite full-text search. Output labels distinguish evidence from generated material. Sources can be pinned or excluded; current outside facts trigger bounded primary-source research. No Profile, application, resume or settings write tools are provided.

Work Styles summaries require review and explicit AI opt-in. Raw questionnaire answers and private disclosures stay out of automatic coaching context. Published questionnaire items and scoring are unchanged; new app-authored guidance is discipline-neutral. Historical reports retain their original versions. Career Goals cards preserve legacy text and revision checks; future credentials are never qualification evidence.

Job Search separates Search, For You, Ask AI, Compare, Saved jobs and Daily alerts. Ordinary Search makes no AI calls and defaults to all active results, showing confirmed and Needs review counts. For You uses up to five model requests, one bounded web-research pass, a balanced pool of 50 candidates, ten availability checks and at most five supported results. It may return fewer. Public queries omit identifying account details. Adzuna remains account-only under the existing manual-trial rules.

Skills includes resources across seven broad fields, with an optional job target. Interview Practice saves behavioral, STAR, coding, business-case, domain/scenario, presentation and other practice conversations. Coding feedback is conceptual; no user code executes.

All three conversations accept validated chart, timeline, table and diagram data. Rendering never executes model-authored code. Source images use attributed links. Illustration generation is an explicit paid action: one medium-quality 1024-square PNG from GPT Image 2.5 Flare, using the account key. There is no automatic image generation or model substitution. Access depends on the provider account. Unknown charges remain unknown. Images are privately owned, quota-accounted, included in backups and published only after success.

## Safety and verification

The new actions use existing deduplication, recovery, Stop controls and staged publication. Cancelling discards staged outputs while retaining previous records, editable inputs and incurred usage. Imported content remains account-local. Hosted access controls, the 5 GB quota and localhost-specific settings remain in place.

Validation uses fictional accounts and mocked providers, including research, images, source failures, account isolation, imported backups, existing cached searches and cancellation. This does not establish live provider/model entitlement. No paid requests are necessary for navigation or reading history.

The Chrome package is version 1.0.4. Keep an unpacked installation in a permanent folder; deleting its folder breaks popup loading. See EXTENSION-INSTALLATION.md in the local distribution or BROWSER-INSTALLATION.md in the hosted source.
