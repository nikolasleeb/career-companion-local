# Prioritized AI improvements after Career Coach v1

These are proposals, not implemented capabilities. They can use the existing account-owned OpenAI connection; an extra AI provider is not inherently required.

| Priority | Improvement | Implementation approach | Evidence of success |
|---|---|---|---|
| 1 | A bounded research agent | Expose read-only functions for retrieving guidance, checking a specific official resource and comparing supported development options. Let the model choose which function to call inside an explicit user-started run. Limit turns, tool calls and spend; checkpoint each result and preserve read-only recovery. Start with one agent rather than adding multiple agents without a clear need. | The agent selects the right tools for held-out career questions, stops within its budget and returns verifiable citations. Compare it with the fixed v1 pipeline. |
| 2 | Hybrid semantic retrieval | Add embeddings to the existing keyword/alias retrieval, combine rankings and retain account/chat filters before selecting context. Re-embed only changed passages. Keep private corpora separate and account for embedding/storage costs before enabling it. | Better recall for paraphrased goals and cross-discipline language, without reducing citation accuracy or isolation. |
| 3 | Adaptive interview practice | Use the user's chosen roadmap and reviewed accomplishments to select practice questions. Provide evidence-grounded feedback, then adjust the next question based on the answer. Keep practice statements as drafts until the user separately reviews any proposed Profile facts. | Follow-up questions address observed needs; feedback cites actual evidence and never invents achievements. |
| 4 | Offer comparison and career scenarios | Let users enter or upload offer terms. Extract them into a reviewed comparison, distinguish quoted facts from assumptions, and calculate transparent scenarios deterministically. AI explains tradeoffs against user-stated goals and preferences; the user makes the decision. | Correct extraction/calculations, clear assumptions, no fabricated benefits or guaranteed career outcomes. |
| 5 | A reusable evaluation set | Build fictional examples across disciplines and Profile completeness levels. Score retrieval relevance, exact citation validity, unsupported claims, realistic next actions and recovery behavior. Use deterministic assertions for references and account isolation, with human review for coaching usefulness. | Measurable regression thresholds, reproducible fixtures and a short before/after report suitable for the assignment presentation. |

Although listed fifth as a product improvement, a small deterministic evaluation set is already part of v1 testing. Expand it before introducing an agent or semantic retrieval so the team can demonstrate whether those techniques actually improve the experience.
