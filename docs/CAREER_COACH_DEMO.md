# Five-minute assignment demonstration

Use a fictional, reviewed Profile and an already authorized pilot account. If demonstrating live AI, use the account's own configured key and show that the action is explicit. Do not present mocked examples as actual labor-market research.

| Time | Demonstration | Assignment evidence |
|---|---|---|
| 0:00–0:40 | State a student need: choosing useful next skills and a realistic direction. Show the reviewed education, skills and project evidence. | Practical need and document/Profile input |
| 0:40–1:20 | Open Resources → Career Coach. Show optional Career Goals in Profile, then edit a coaching starter. Explain that simply opening the page makes no AI request. | Personalized inquiry and user control |
| 1:20–2:10 | Send a roadmap question. Explain the visible stages: source research, retrieval, generation and validation. | Retrieval-augmented generation in a deployed app |
| 2:10–3:00 | Open a recommendation's Profile evidence and source excerpts. Contrast original guidance with a fetched source and its date. | Grounding, attribution and evaluation of limitations |
| 3:00–3:45 | Ask for a smaller first step or a free alternative. Inspect the proposed changes and explicitly update the roadmap. Mark one activity in progress. | Interactive coaching, saved versions and actionable next steps |
| 3:45–4:20 | Demonstrate Stop using a fictional delayed provider, then reopen the completed chat from Your chats. Show its roadmap and progress are intact. | Account-owned persistence and complete workflow |
| 4:20–5:00 | Show the usage ledger and discuss testing. State that keyword/alias retrieval is implemented. Show Career Readiness for the separate bounded SDK agent; Action Plans retains its fixed pipeline. Semantic embeddings remain a proposed extension. | Technical understanding, truthful scope and completeness |

Architecture to show: **Reviewed Profile + goal → scoped retrieval + current public sources → structured response → evidence checks → saved chat and roadmap.**

Be explicit about limits: a small retrieved library is not the entire job market; an absent Profile statement is not proof of a missing skill; a credential or checklist does not guarantee employment. Explain how source-reference tests, isolation tests and failure/recovery tests address these limitations.
