# Individual project checkbox

1. In Profile → Resume content → Projects, choose Add project. Enter a fictional title and description, then check **Individual project**. The contribution field becomes **Additional contribution details (optional)**, without asking about teammates. It may remain blank.
2. The accuracy confirmation remains separate. Save a confirmed project, reopen it, reload the page and reopen again. The checkbox should stay checked and its Profile card should say Individual project.
3. Enter contribution text, check and uncheck the box. Neither the description nor contribution text should be erased. Cancelling the edit must leave the saved record unchanged. Unchecking and saving removes the Individual project label without labeling the project as a group project.
4. The same checkbox is available in imported project drafts. Checking it does not save Profile before final import approval. Source parsing and old records must not infer an individual/team designation from wording or repository ownership.
5. Only confirmed projects send the individual-project context to the coach and resume workflows. The label alone must not generate achievements, proficiency or authorship claims. Existing descriptive bullets remain the resume content.
6. Export and restore an ordinary account backup. The checked value and contribution text should remain. Older records/backups without the field open unchecked. Another account cannot edit the record.
7. Verify keyboard and narrow mobile operation. No AI request is required for saving or changing the checkbox.
