# Adjustable Career Coach and writing help

Both assistant scopes use a shared presentation width. The default is 480px; the resize separator supports pointer dragging, Left/Right (20px), Shift+Left/Right (40px), Home (360px) and End (the available maximum). Docked width is capped at 800px while leaving 480px for the task beside navigation. A browser-local preference is scoped to the signed-in account and is never overwritten by temporary viewport clamping. Expand overlays the task area up to 1100px, preserving navigation; Restore returns to the docked preference. Reopening starts docked.

The compact toolbar provides New conversation, History, Context and More. History and Context replace the reading area without unmounting its contents. More provides assistant switching and conversation naming/renaming. Escape returns from a drawer before closing the panel. The composer remains anchored, grows within a height cap and supports Ctrl/Cmd+Enter to send; ordinary Enter remains a newline. Opening, resizing and drawer navigation make no AI request.

Writing help retains its reviewed-writing scope, icon and green presentation. General Coach retains its existing permitted context and retrieval behavior. Histories, citations, unsent drafts, handoff protections, modal suspension and saved-request recovery use the existing mechanisms. A narrower task area stacks document editing and preview instead of forcing columns offscreen. The usage badge and launcher share the docked width; expanded mode places the badge in the header and hides the redundant launcher.

Verification covers both desktop editions at 1280, 1600 and 1920px, 720px height and 125% desktop scale emulation. Fictional-account browser scenarios exercise pointer/keyboard resizing, width persistence and viewport recovery, Expand/Restore/reopen, drawers, scroll and draft preservation, separate assistant drafts, composer growth/newlines, simulated send failure, saved-request recovery without repetition, modal suspension, document discussion preservation, and account isolation. Frontend suites, production builds, focused backend personalization/retrieval tests and public-source audit are required before delivery. No paid user-account requests or mobile checks; installed localhost remains unchanged.

Context checkboxes use centered checkbox/label pairs with independent text spans so shared form styles cannot offset them. Pin prioritizes an eligible saved source within retrieval limits; Exclude omits it. Both remain subject to existing permissions and do not edit Profile records.

Assistant request progress is routed to the composer area while its panel is open: a compact spinner, actual stage, elapsed time and Stop action. Starting, polling, uncertain status and recovered knowledge-coach tasks retain that destination. Closing the assistant restores the normal page progress banner; unrelated tasks retain their existing placement. Modal progress hosts retain priority. The same processing store, cancellation endpoint and saved-request recovery remain in use; presentation metadata stays client-side.
