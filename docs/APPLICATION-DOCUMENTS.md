# Applications with your own documents

1. Start an application and upload a posting PDF, DOCX, or TXT. Choose **Read posting with AI**, review the populated details, and save the posting. This imports the posting only; it does not run a Profile comparison or generate a resume.
2. Choose **Upload my resume**, **Generate a resume**, or **Save without a resume**. You can save and return to Applications with no resume attached.
3. After uploading, choose **Save & return to Applications** or **Continue to cover letter**. Before drafting a cover letter, review and confirm the extracted resume text. If a scan has no selectable text, paste its text for review. The uploaded original remains unchanged.

In Applications, open an entry's details or choose **Progress & history**. Under **Application documents**, select a category and upload a resume, cover letter, interview preparation, email communication, or other supporting file. Files are saved immediately. Other changes, including status and the submitted resume selection, use **Save application**.

Uploaded and generated resumes are labeled separately. Choose the exact version in **Resume submitted**; uploading a new version never changes that field automatically. A generated draft finishing later does not replace an explicitly selected uploaded resume.

## Files and source history

- Application attachments accept PDF, DOCX, and UTF-8 TXT, up to 10 MB each and 30 pages for paginated documents. Posting PDFs retain their separate limit of less than 50 MB / 30 pages.
- Downloads return the original uploaded bytes and format. Uploaded resumes have no one-page restriction and are not resized or reformatted.
- Supporting attachments are stored only. They are not sent to AI, added to Profile, or offered as documents to the extension. Cover-letter drafting uses the reviewed selected resume and explicitly reviewed answer sources.
- Reviewed resume text is immutable. Upload a new version if it needs correction. Exact original files and references are included in account backups.
- Files referenced by a submitted resume, a cover-letter workspace/version, or an assistant run cannot be removed while those references remain. Archive an application to retain its history.
- The status-change date starts at today's local calendar date, remains editable, and can be cleared if unknown. Existing history dates remain unchanged.

Routine application filling remains deterministic. It preserves existing values, uses explicit approval of exact document versions, and never submits the employer application automatically.
