# Work Styles summary and AI access

Profile keeps Assessment at a glance and Open full Work Styles assessment above the summary workspace. Generate summary is an explicit paid action, with a local cost estimate. Drafts appear above the generation button. The attached revision box requests changes with one model call; each replacement must be reviewed before saving. Manual edits remain free. Generation never changes a saved paragraph or enables sharing automatically.

Use Work Styles for AI guidance takes effect only after review and Save summary & AI guidance. It enables two distinct scopes:

- The global Career Coach can retrieve the saved summary plus the explicitly shared account-owned assessment report, dimension/facet scores and optional work-comparison choices. Raw questionnaire answers are never included. Reports are self-reflection, not diagnoses, qualifications or hiring predictions, and must not enter public research queries.
- Other career guidance and AI resume wording receive only the reviewed summary. Resume claims must still use reviewed professional evidence. Reports, scores and raw answers do not enter resume generation.

Existing summary-only permissions do not gain report access automatically. Saving the expanded scope requires renewed review. A later assessment is not automatically substituted for the report previously shared. Turn guidance off and save to revoke access for new requests. Earlier conversation snapshots remain historical records. Account imports restore summaries with all sharing off until reviewed again.

Summary drafting itself still uses only explicit work-comparison choices, saved work-style statements and user-supplied notes/draft. It excludes questionnaire ratings and assessment scores, uses no web search and makes no automatic paid retries. Existing request recovery, Stop, costs and revision checks remain in force.
