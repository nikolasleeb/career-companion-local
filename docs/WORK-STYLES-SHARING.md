# Work Styles summary and AI access

Work Styles keeps the local assessment separate from professional evidence. A reviewed safe summary can guide AI wording and advice when sharing is enabled. Ordinary guidance and Career Coach do not receive raw questionnaire answers, assessment scores or the full report. Legacy report-sharing fields do not override the current context projection.

Explicit summary generation can use up to five broad domain averages and interpretations, work-comparison choices, user notes and an existing saved summary, plus confirmed work examples when explicitly selected. It excludes raw ratings and sensitive facets. Generating or revising a summary is a user-started paid action; review and save the result separately. Editing manually makes no AI request. Turning sharing off affects new requests; historical snapshots remain saved.
