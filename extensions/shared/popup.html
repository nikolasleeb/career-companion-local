Connection & installation help

Keep Career Companion signed in and open. A refreshed app tab reconnects automatically; a closed tab needs Connect this browser again. Approve the matching code there once, then return to the employer tab. Filling resumes only when you choose it.

For an update, extract the latest Chrome package into a permanent folder outside Downloads, such as Applications/Career Companion Extensions/chrome, and load that folder, then choose Reload in chrome://extensions. Reconnect if the browser cleared your session.
